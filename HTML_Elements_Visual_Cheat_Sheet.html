How to read the examples

Opening + closing tags

<p>Hello</p> opens a paragraph, contains text, then closes it.

Void elements

Elements such as img, br, hr, input, and meta do not wrap content and have no closing tag.

Semantic HTML

Choose elements by meaning (for example, nav for navigation), not just by how they look.
